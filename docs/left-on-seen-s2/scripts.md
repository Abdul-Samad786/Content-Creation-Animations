# Left on Seen — Season 2 scripts (plain drafts)

Source of truth for story: the Season 2 bible (canon tables in the production brief).
Source of truth for format: `src/content/left-on-seen-s2/<episode>/episode.json`.

Conventions used below:
- `MIA:` / `BYTE:` / `BYTE 2.0:` / `ZARA (📞):` / `MOM (📞):` are spoken lines.
- `[BEAT]` is a silent action beat.
- `LEO 💬` is a chat bubble. Leo is never shown and never voiced.
- `POPUP` is Byte's on-screen update notification (the running gag).
- `(fake-chill)` marks Mia's flat, fake-casual voice. Byte calls it out.
